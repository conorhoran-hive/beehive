Four ways to show Beehive's track record in the hero

Each variant is a self-contained HTML/CSS block that sits to the right of the hero copy. The motion runs entirely on the GPU (transform and opacity only), with no images, fonts or libraries to download. Use the toggle on each one to preview it on a light or a dark header.

Hive Stack

Four slabs float at different depths over a faint honeycomb. The scene tilts slightly toward the cursor on desktop. It's the most editorial option, and the AED figure leads.

Page speed

  • Each variant is about 2.5 KB of CSS plus about 2 KB of markup. It makes no network requests and uses no images or web fonts of its own.
  • Only transform and opacity are animated, so the browser composites them off the main thread. That means no layout shift and no repaint.
  • The optional script (about 0.6 KB) pauses all motion while the graphic is offscreen and adds the cursor tilt. Load it with defer.
  • Under prefers-reduced-motion, every variant renders as a still composition. The prism unfolds into a 2 × 2 grid.

Copy to confirm before launch

  • "disbursed", not "dispersed". Disbursed is the lending term for money paid out to borrowers.
  • e& or etisalat: Etisalat Group rebranded as e& in 2022, and the site already says "an e& enterprise company", so I've used e&. Switching the wording is a one-word change.
  • Backers: the names are set as plain type. Swap in the approved logo SVGs, and get compliance sign-off on the wording "Backed by" before it goes live.
  • The live site still shows "5,000+ SMEs" and "4.3bn" elsewhere. Align those with 3,300+ and AED 5.4bn+ so the hero doesn't contradict the rest of the site.

Webflow build

  • Paste the shared base CSS and the chosen variant's CSS into the page's custom code (head). Then paste the markup between the ▼/▲ comments into an Embed element in the hero's right-hand column.
  • On a dark header, add data-surface="dark" to the .bh element.
  • Everything scales with the column width (container units), so it keeps working down to a 343px phone column. On mobile it sits under the CTA.
  • Replace the red hex values with the exact Webflow swatches. The snippets inherit the site's typeface.
